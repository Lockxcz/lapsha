# Гид по барному меню — сайт для сотрудников

Статический сайт (без сборки) + Supabase (база данных, авторизация, хранилище фото).
Публичный гид открыт без входа. Редактирование текста, фото и дизайна — через скрытую
админ-панель, доступную только по логину и паролю.

```
site/
├─ index.html            публичный гид
├─ robots.txt            запрещает индексацию /panel-.../ поисковикам
├─ netlify.toml          конфиг Netlify
├─ assets/
│  ├─ config.js          сюда вписываются данные вашего Supabase-проекта
│  ├─ style.css          дизайн (тема, print, reduced-motion, адаптив)
│  ├─ icons.js           иконки категорий
│  └─ app.js             логика публичного сайта (поиск, фильтры, scroll-spy)
├─ admpan/         админ-панель (переименуйте папку перед деплоем!)
│  ├─ index.html
│  ├─ admin.css
│  └─ admin.js
└─ supabase/
   └─ schema.sql         SQL-схема: таблицы, RLS-политики, хранилище
```

## Шаг 1. Создать проект Supabase

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) → **New project**.
2. Дождитесь инициализации проекта.
3. Откройте **SQL Editor → New query**, вставьте содержимое файла
   `supabase/schema.sql` целиком и нажмите **Run**.
   Скрипт создаст таблицы `settings`, `categories`, `item_groups`, `items`,
   политики безопасности (RLS) и публичный bucket `guide-media` для фото.

## Шаг 2. Создать логин администратора

Публичной регистрации в системе нет — учётные записи создаются вручную,
это и есть защита админ-панели.

1. **Authentication → Users → Add user**.
2. Укажите email и пароль сотрудника, которому разрешён доступ к редактированию.
3. Повторите для каждого администратора. Позже пароль можно сменить там же.

## Шаг 3. Подключить сайт к Supabase

1. **Project Settings → API** — скопируйте `Project URL` и `anon public` ключ.
2. Откройте `assets/config.js` и впишите их:

```js
window.SUPABASE_URL = 'https://xxxxxxxx.supabase.co';
window.SUPABASE_ANON_KEY = 'eyJhbGciOi...';
```

`anon` ключ публичный по своей природе — он не даёт прав на запись,
запись защищена RLS-политиками (только авторизованные пользователи).

## Шаг 4. Скрыть и переименовать админ-путь

Папка `panel-7f3k9x` — это адрес входа в админку
(`https://ваш-сайт.netlify.app/panel-7f3k9x/`). Перед деплоем **переименуйте
папку** в свой уникальный путь (например `panel-lbw-9k2x4z`), чтобы адрес
нельзя было угадать. Ссылок на эту папку с публичного сайта нет,
`robots.txt` и мета-тег `noindex` дополнительно скрывают её от поисковиков.

## Шаг 5. Деплой на Netlify

**Вариант А — перетаскиванием:**
1. [app.netlify.com](https://app.netlify.com) → **Add new site → Deploy manually**.
2. Перетащите папку `site` (со всем содержимым) в окно загрузки.
3. Сайт будет доступен по адресу вида `https://имя-сайта.netlify.app`.

**Вариант B — через Git (рекомендуется, чтобы обновлять сайт пушем):**
1. Загрузите содержимое папки `site` в репозиторий на GitHub.
2. В Netlify: **Add new site → Import from Git** → выберите репозиторий.
3. Build command — оставить пустым, Publish directory — `.` (уже задано в `netlify.toml`).

## Шаг 6. Наполнение контента

Откройте `https://ваш-сайт/ваш-админ-путь/`, войдите под созданной учётной
записью и последовательно:
1. **Общие настройки** — загрузите логотип, впишите название, заголовки и подберите цвета.
2. **Категории** — уже созданы 11 базовых разделов из вашего PDF (Кофе, Чаи и т.д.),
   их можно переименовать, добавить новые или удалить лишние.
3. **Напитки** — выберите категорию и добавляйте позиции: состав, вкус, аромат,
   послевкусие, «как презентовать гостю», теги-настроение и фото.
   Все поля одинаковы для любой категории — единообразие гарантировано структурой.

Изменения появляются на публичном сайте сразу после сохранения — обновлять
код или переразвёртывать сайт не нужно.

## Что уже учтено по вашему списку правок

- **Единообразие «как презентовать гостю»** — поле есть у каждой позиции в любой
  категории, включая безалкогольные напитки.
- **Полнотекстовый поиск** — ищет по названию, тегам, тизеру и всем раскрытым
  полям (вкус, аромат, послевкусие, состав, факт, презентация).
- **Кликабельные теги-фильтры** — клик по чипу на карточке фильтрует весь список
  по этому тегу; есть панель «Фильтр: … / Сбросить».
- **Фото напитков** — загружаются в админке, отображаются в карточках
  (без фото карточка просто без фото — не ломает вёрстку).
- **Scroll-spy** — чипы категорий в шапке подсвечивают текущий раздел при прокрутке.
- **prefers-reduced-motion** — все анимации и плавная прокрутка отключаются для
  пользователей с этой системной настройкой.
- **Стили печати** — при печати (Ctrl/Cmd+P) убираются шапка, поиск, декоративные
  элементы, остаётся чистая шпаргалка на белом фоне.
- **Доступ без авторизации на сайте** — `index.html` полностью открыт.
- **Скрытая админ-панель с логином** — уникальный ненаходимый путь + вход по
  email/паролю через Supabase Auth, регистрация закрыта.

## Обслуживание

- Добавить нового администратора — Supabase → Authentication → Users → Add user.
- Забыли пароль — сброс там же, кнопка «Send password recovery».
- Резервная копия контента — Supabase → Table Editor → экспорт таблиц в CSV,
  либо Database → Backups (на платных планах — автоматически).
