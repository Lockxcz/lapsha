LAPSHA GUIDE — ОБНОВЛЕНИЕ V2
============================

Что меняется
------------
1. Новости становятся крупными горизонтальными карточками.
   - Можно добавлять много новостей.
   - На телефоне — свайп влево/вправо.
   - На компьютере — стрелки + горизонтальный скролл.
   - Показываются дата и порядковый номер.

2. Описание категории переносится прямо под название категории.
   Пример:
   КОФЕ
   «Классические и авторские кофейные напитки…»

   Ничего в базе менять не нужно: используется уже существующее поле
   «Краткое описание раздела» в админке.

3. Справа снизу появляется лупа.
   - Нажать → ввести название / вкус / состав / категорию.
   - Нажать на результат → сайт сразу прокрутится к нужному напитку.
   - Блок «Подробнее» автоматически раскрывается.
   - Ctrl+K / Cmd+K тоже открывает быстрый поиск.

4. Рамки напитков.
   В поле «Теги-настроение» можно поставить специальные теги:
   - ALCO — красная рамка + ALCO;
   - NON ALCO — синяя рамка + NON ALCO;
   - ICE или COLD — голубой холодный акцент + ICE/COLD.
   - Если специальных тегов нет — обычная карточка без рамки.

5. В админке рядом с тегами появляются быстрые кнопки:
   + ALCO / + NON ALCO / + ICE / + COLD / Без рамки.

6. В админке появляется плавающая кнопка «Предпросмотр сайта».

Предпросмотр до установки
-------------------------
Откройте файл PREVIEW.html двойным кликом. Это демонстрационный макет нового вида — он не подключается к вашей базе и ничего не изменяет.

Установка
---------
Вариант А — автоматически (Windows):
1. Распакуйте папку lapsha-update-v2 куда угодно.
2. Откройте папку вашего репозитория lapsha.
3. Скопируйте в корень репозитория всю папку lapsha-update-v2.
4. В адресной строке Проводника напишите cmd и нажмите Enter.
5. Выполните:

   lapsha-update-v2\\apply-update.bat

6. Скрипт сам:
   - сделает backup index.html и admpan/index.html;
   - скопирует новые CSS/JS;
   - подключит их к сайту и админке.

7. Загрузите изменения в GitHub / сделайте commit + push.
8. Netlify автоматически пересоберёт/обновит сайт.

Проверка
--------
1. Откройте админку.
2. Категории → Кофе → заполните «Краткое описание раздела» → Сохранить.
3. Напитки → откройте напиток → нажмите, например, NON ALCO + ICE → Сохранить.
4. Новости → добавьте 4–10 новостей.
5. Нажмите «Предпросмотр сайта».
6. Проверьте:
   - описание под «Кофе»;
   - свайп новостей;
   - синюю/голубую рамку напитка;
   - лупу справа снизу.

Откат
-----
После установки рядом с исходными файлами будут резервные копии:
- index.html.bak-lapsha-v2
- admpan/index.html.bak-lapsha-v2

Если нужно полностью убрать обновление, восстановите эти два файла и удалите:
- assets/lapsha-update-v2.css
- assets/lapsha-update-v2.js
- admpan/admin-update-v2.js
